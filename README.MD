# Budi LED — LED Display & Lighting Solutions

Website company profile dan katalog produk untuk Budi LED.

## Tentang Proyek

Budi LED menyediakan solusi teknologi LED untuk kebutuhan bisnis dan komersial.

Website ini dibuat untuk memperkenalkan produk, menampilkan informasi perusahaan, serta memudahkan calon pelanggan melakukan konsultasi.

## Produk

- Running Text
- LED Display Indoor
- LED Display Outdoor
- Videotron

## Teknologi

- HTML5
- CSS3
- JavaScript
- Git & GitHub

## Fitur Website

- Responsive design
- Katalog produk
- Galeri produk
- Dark mode dan light mode
- Form konsultasi melalui WhatsApp
- Navigasi mobile

## Menjalankan Proyek

1. Clone repository ini.
2. Buka folder proyek menggunakan Visual Studio Code.
3. Jalankan `index.html` melalui browser atau ekstensi Live Server.

## Deployment

Website dipublikasikan menggunakan GitHub Pages.
