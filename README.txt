CARA MENJALANKAN
1. Extract folder AALED-Website.
2. Buka folder tersebut di Visual Studio Code.
3. Buka index.html di browser, atau gunakan extension Live Server.
4. Pastikan folder assets/aaled-hero.png tetap berada di dalam folder assets.
